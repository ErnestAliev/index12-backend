# Слияние контрагентов

`scripts/merge-contractors.cjs` по умолчанию только анализирует справочник принадлежащей владельцу рабочей области:

```sh
node scripts/merge-contractors.cjs --actor OWNER_ID --workspace WORKSPACE_ID
node scripts/merge-contractors.cjs --actor OWNER_ID --workspace WORKSPACE_ID --apply --expected-plan HASH_FROM_ANALYSIS
```

Использует `DB_URL` из `.env`. Требуется MongoDB с поддержкой транзакций. Сохраняет первую карточку по `createdAt` либо времени ObjectId, объединяет совместимые реквизиты, переносит ссылки операций/счетов и удаляет дубли в одной транзакции. Различающиеся ИИН/БИН, конфликтующие реквизиты и дополнительные связи с задачами или неизменяемыми планами останавливают слияние. Изменение данных после анализа отклоняет ранее рассчитанный план.

Полные исходные карточки и затронутые записи сохраняются в `contractorMergeJournal` вместе с владельцем, рабочей областью и временем. У финансовых записей меняется только ссылка на контрагента и версия; состав и финансовые поля операций проверяются перед фиксацией. Автоматического восстановления из архива нет: оно требует отдельного запроса и проверки последующих изменений.

Локальная проверка на отдельной временной базе: `node tests/integration/merge-contractors.cjs`.
