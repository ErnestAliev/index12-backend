# Подключение оригинального PDF счёта из 1С

Для обслуживающей организации 1С:Fresh. INDEX12 создаёт документ через OData;
нужна выдача его штатной печатной формы, а не новый документ или новый макет.
До подключения сервиса используется встроенный генератор INDEX12; публикация
позволит выдавать оригиналы 1С. Настройка нужна только для штатной печати.

## Что требуется на стороне 1С

1. Опубликовать в той же базе HTTPS HTTP-сервис, например с корневым адресом
   `hs/index12-print/`. Это предлагаемый адрес нового сервиса, не встроенный
   метод OData. Установку и публикацию в Fresh выполняет поставщик сервиса.
2. Для сохранённого `Документ.СчетНаОплатуПокупателю` вызывать ту же штатную
   команду печати, которую пользователь выбирает в форме документа. Реальный
   идентификатор команды и вызов менеджера печати определить по установленной
   конфигурации. Не переносить макет в расширение, не пересчитывать строки,
   не менять настройки печати, не использовать HTML/скриншоты/другой генератор.
3. Экспортировать полученный штатный табличный документ в PDF средствами 1С.
   Возвращать его байты непосредственно в ответе HTTP.
4. Работать с обычными правами пользователя: чтение конкретной организации и
   документа с соблюдением ограничений доступа. Не включать привилегированный
   режим, не предоставлять анонимный доступ, не создавать новые учётные записи.
   Используется существующая учётная запись интеграции; пароли в код не включать.
5. Запись, проведение, пометка удаления, отправка почты и создание финансовых
   документов этому сервису не нужны. Расширение не должно выполнять их.

## Методы

`GET capabilities` — JSON в UTF-8:

```json
{
  "protocol": "index12-print-v1",
  "forms": [
    {
      "collection": "Document_СчетНаОплатуПокупателю",
      "id": "<реальный идентификатор штатной команды>",
      "version": "<ASCII-версия конфигурации и редакции печатной формы>",
      "default": true
    }
  ]
}
```

При изменении используемого штатного макета меняется `version`. `default`
нужен, если публикуется несколько форм. Клиент не выбирает случайную первую.

`POST print` — JSON в UTF-8:

```json
{
  "collection": "Document_СчетНаОплатуПокупателю",
  "id": "<GUID существующего счёта>",
  "organizationRef": "<GUID его организации>",
  "dataVersion": "<DataVersion из OData>",
  "formId": "<id из capabilities>",
  "formVersion": "<version из capabilities>",
  "format": "pdf"
}
```

До печати проверить права, тип документа, GUID организации, отсутствие
пометки удаления, DataVersion и идентификатор/версию формы. После формирования
повторно проверить версию документа. При изменении вернуть HTTP 409 без PDF.
Недостаточные права — HTTP 403; отсутствующий документ — 404; неверный
запрос — 400. Ошибка не должна содержать пароли или трассировку с реквизитами.

Успешный ответ — `Content-Type: application/pdf`, до 10 МБ и заголовки:

- `X-1C-Document-Ref`: GUID именно напечатанного документа;
- `X-1C-Organization-Ref`: GUID проверенной организации;
- `X-1C-Data-Version`: версия именно напечатанного документа;
- `X-1C-Form-Version`: ASCII-версия именно использованной штатной формы.

Поля должны совпадать с запросом. Публичные ссылки на документы, доступ
без авторизации и перенаправления на сторонние сайты не нужны.

## Что передать для настройки INDEX12

- Фактический HTTPS-адрес опубликованного сервиса в этой же базе.
- Идентификатор штатной команды печати и версию формы.
- Подтверждение, что существующий пользователь интеграции имеет доступ.

На сервере INDEX12 задаётся `ONEC_PRINT_BASE_URL`; при нескольких формах без
`default` дополнительно `ONEC_PRINT_FORM_ID`. Логин и пароль уже используются
из `ONEC_USERNAME`/`ONEC_PASSWORD`; создавать или передавать новые не требуется.

Подключение можно завершить на уже существующем счёте: создавать тестовые
счета, покупателей, проводить документы или менять финансовые данные не нужно.
Самостоятельная загрузка файла расширения и публикация HTTP-сервиса — разные
права. Каталог готовых расширений в кабинете абонента Fresh не заменяет публикацию.

Основания для реализации: [HTTP-сервисы в расширениях — 1С](https://wonderland.v8.1c.ru/blog/web-i-http-servisy-v-rasshireniyakh/),
[подсистема печати БСП — 1С](https://1c-dn.com/library/tutorials/1c_standard_subsystems_library_3_1_11/).
