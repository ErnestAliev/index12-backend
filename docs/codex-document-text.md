# Извлечённый текст документов Codex

PDF и непосредственно загруженные изображения распознаются отдельным вызовом без финансовых инструментов. Ответ сохраняется в `cloudMessages` до продолжения сценария; `cloudDocumentTexts` связывает его с оригиналом в пределах actor/workspace/chat. Основной агент получает текст и ссылку на оригинал. PDF и его OpenAI file ID не передаются в следующие шаги или Python-контейнер оркестрации.

Повторные чтения через MCP, в том числе из Code Mode, возвращают сохранённый текст вместо байтов. Для одинаковых новых загрузок используется SHA-256. История старых чатов связывается с уже имеющимся ответом без распознавания файла заново. Разбор доступен и после выхода исходного сообщения за пределы страницы истории.

Выделение текста ответа → карандаш → «Сохранить» вызывает `POST /api/codex/chats/:id/messages/:messageId/corrections`. Проверяются принадлежность чата, отсутствие активного задания, версия текста и выбранное вхождение. Исходный Markdown сохраняется, исправления содержат автора, дату и новую версию. Фронтенд изменяет только текстовые узлы; агент получает актуальный текст и указание на правки пользователя. Сохранение исправления не создаёт задание агенту и не изменяет уже созданные финансовые документы.

Оригинал можно копировать/прикреплять по сохранённому ID. Это не повторное распознавание. Фото/видео из рабочих задач по-прежнему требуют разрешения перед первым просмотром. Отсутствие проекта не останавливает оформление; действительно обязательные неизвестные поля собираются одним вопросом. Банк не вызывается.

Проверки: `node --test tests/document-text.test.cjs`, `node tests/integration/cloud-chat.cjs`; фронтенд — `node tests/browser/message-fragments.mjs` и `--webkit`. Интеграционный сценарий использует изолированную MongoDB и имитацию OpenAI, проверяя ошибку после извлечения, правку, длинную историю, повторное чтение и загрузку одинакового PDF с другим ID.
