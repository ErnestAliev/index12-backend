# Согласование внутри рабочей задачи

Пункт «Добавить согласование» находится только в меню плюса обсуждения задачи,
между подзадачей и файлом. Диалог выбирает одного/нескольких действующих
участников (включая владельца) через тот же выбор сотрудников, что задачи.
Черновик обычного сообщения сохраняется.

`POST /messages`: `id`, `taskId`, `text`, `approvalRecipientIds`. Сервер создаёт
`kind=approval_request`, `approvalRequest.recipients` с доверенными именами и
исходным `pending`. Это обычная хронологическая запись обсуждения, не отдельная
закреплённая панель. Доступ выбранных согласователей и запись сообщения
фиксируются вместе в MongoDB-транзакции. `approvalActorIds` даёт участие в
задаче для сотруднического MCP, не меняя исполнителей и прав редактирования.

Уведомления о запросе адресуются каждому выбранному актору через `onlyActor`,
ссылки содержат `taskId` и `messageId`. Автор получает уведомление о решении.
Повторы создания и голосования не создают новые записи/уведомления.

`POST /messages/:id/decision`: `action=approve|reject`, `expectedVersion`,
необязательный `note`. В этом типе сообщения решает только выбранный актор,
включая владельца: отвечать за другого человека нельзя. Первый ответ актора
неизменяем, такой же повтор безопасен. Старшая версия, изменённая только
ответом другого согласователя, допускает независимый голос; CAS и повторное
чтение предотвращают потерю параллельных ответов.

Итог: `approved` после всех согласований, `rejected` сразу при первом отказе,
иначе `pending`. Другие выбранные люди могут ответить и после отказа — их
решения сохраняются. Изменять текст/файлы запроса нельзя; для нового контекста
создаётся новое согласование. Удалённая задача/запись не принимает решения.
Старое ролевое согласование обычных сообщений остаётся прежним.

Проверки: `node tests/integration/team-chat.cjs`,
`node tests/integration/team-chat-mcp.cjs`, `npm test` (backend),
`NO_SCREENSHOTS=1 npm run test:chat-ui` (frontend). Новые сценарии входят в
`test:task-approvals`: порядок и выравнивание меню, несколько согласователей,
решения, хронология, клавиатура/касания, темы, безопасные области и размеры
390/834/1280 в Chromium/WebKit. Изображения не создаются.
