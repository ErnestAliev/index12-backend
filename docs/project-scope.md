# Общие платежи по всем проектам

`Event.projectScope`: `selected` (по умолчанию, в том числе для старых операций) или `all`.

- `all`: один доход, расход или перевод; `projectId: null`, без дочерних долей. Не создаёт запись справочника Project. Учитывается один раз в общих итогах. В разбивках проектов попадает в отдельную строку `__all_projects__` / «Все проекты».
- `selected`: один проект либо существующее равное распределение по явно выбранным проектам. Родитель распределённого платежа исключён из сумм; в расчётах участвуют его доли. Равные доли сохраняют каждый тиын, остаток распределяется по одному тиыну.
- При редактировании основного платежа можно переключиться между общим платежом и распределением. Сервер обновляет/удаляет производные доли; HTTP-ответ содержит `allocationChanges`, чтобы интерфейс инициатора тоже обновился при подавлении собственных socket-событий.
- Дочернюю долю нельзя отдельно переключить на «Все проекты»: редактируется основной платёж.
- Внутренние переводы сохраняют привязку, но не входят в доход/расход/прибыль проектов.
- Общая строка соблюдает фильтры видимости счетов и периода и отделяет факт от плана.

«Все проекты» — общий пул **без распределения**, включая проекты, добавленные позднее. Индивидуальная прибыль показывает доходы минус прямые/явно распределённые расходы. Для чистой прибыли каждого проекта необходимо задать обоснованное распределение общих расходов; автоматического копирования всей суммы в каждый проект нет. В интерфейсе это поясняют подсказки.

Старым операциям отдельная миграция не нужна. Поле можно добавить при обычном редактировании. Экспорт JSON сохраняет поле, табличный экспорт — метку «Все проекты», импорт распознаёт эту метку или `projectScope: all`.

Проверка на изолированной MongoDB (не читает .env):

```sh
node tests/integration/project-scope.cjs --browser
```
